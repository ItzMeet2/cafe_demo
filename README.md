# CAFÉ — Minimalist Architecture & Platform Showcase

A minimal, Scandinavian/Japanese-inspired specialty coffee web application designed for real cafe operations and client walk-in demonstrations.

## Design Philosophy

- **Zero Emojis & Zero AI Gimmicks:** Quiet, editorial typography (Playfair Display + Space Mono + Plus Jakarta Sans).
- **Understated Palette:** Rich Warm Obsidian Charcoal (`#121110`), Warm Sand (`#C4A480`), Soft Bone White (`#ECE7DF`), and Stone Borders (`#2B2824`).
- **Core Real-World Hospitality Features:**
  1. **Direct Menu & Bag Checkout:** Commission-free online ordering for table delivery or counter pickup.
  2. **Table 07 QR Service:** Seated customers order to their seat and request water, check, or staff assistance.
  3. **Table Reservations:** Quiet, simple floor plan booking.
  4. **Browser Loyalty Strip:** Digital 6-stamp card with zero printing or app downloads.
  5. **Kitchen Display Screen (KDS):** Real-time web ticket tracker for baristas.
  6. **Agency Pitch Mode:** Clean financial commission recovery calculator for cafe owner visits.

## Quick Start

```bash
# Run local dev server (default port: 5173)
npm run dev

# Build production bundle
npm run build
```
